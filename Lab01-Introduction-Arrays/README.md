## Module Overview
Lab 01 establishes core foundational data structures using contiguous memory in C.

| Program | Title | Primary Operations | Complexity |
|---|---|---|---|
| [Program 01](Program01-ArrayOperations/) | 1D Array Operations | Insert, Delete, Search, Rotate, Reverse | $O(n)$ time, $O(1)$ space |
| [Program 02](Program02-2DArrayOperations/) | 2D Array Operations | Row/Col Shift, 90° Rotate, Spiral Traversal | $O(R \times C)$ |
| [Program 03](Program03-SparseMatrix/) | Sparse Matrix (3-Tuple) | Triplet Conversion, Fast Transpose, Add | $O(cols + non\_zeros)$ |
| [Program 04](Program04-MatrixCalculator/) | Matrix Calculator | Add, Multiply, Transpose, Determinant, Inverse | $O(n^3)$ |

Detailed reflections and optimizations are documented in [`reflection.md`](reflection.md).
